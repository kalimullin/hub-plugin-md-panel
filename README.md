# Markdown в панели справа — плагин Agents Hub

Клик по ссылке на `.md` в разговоре сессии открывает файл в панели справа от ленты, а не в новой вкладке: читаете
отчёт или план сессии, не уходя из разговора и не теряя место в ленте.

- Внутри — «Файлы» хаба во встроенном окне: рендер и исходник, правка, комментарии к выделенному куску (ответит
  сессия), Finder и VS Code.
- Панель — штатная панель хаба справа от сессии: то же скруглённое окно, что у чата; ширина тянется за край.
- Закрыть — ✕ или Esc. ⌘/Ctrl-клик — как без плагина, новой вкладкой. ↗ — открыть файл в «Файлах» отдельно.
- На телефоне файл открывается поверх ленты.

Ловит ссылки на `.md` в «Файлах» (`/open?path=…`, `/#/<корень>/<путь>.md`) и `file:///…/*.md`, пока открыта сессия.

Место — `session.aside`, нужен API плагинов 1.14 (`ctx.open()`); встроенное окно без списка папки — «Файлы» с `embed=1`.

## Поставить

«Настройки» → «Плагины» → найти «md-panel» или вставить ссылку на этот репо → «Проверить и поставить».
